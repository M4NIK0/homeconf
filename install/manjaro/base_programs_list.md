# What is it?

This is a complete list of programs that are not installed through commands (yet/ever)

Those can be found and installed easily through a simple sarch using your favorite search engine!

## AI tools

- [LMStudio](https://lmstudio.ai/)
- [StabilityMatrix](https://github.com/LykosAI/StabilityMatrix)
    - Use Forge - Neo webUI for easier use
    - Dont forget to put in its own folder!

## 3D tools

- [Fusion360](https://codeberg.org/cryinkfly/Autodesk-Fusion-360-on-Linux)
    - Use proton for this one! the setup is MUCH more stable
- [CrealityPrint](https://www.creality.com/download#sparkx)/[OrcaSlicer](https://www.orcaslicer.com/download/)
    - Slicer for 3D printing, native linux compatible as appimage

## Graphics tools

- [Paint.software](https://github.com/Univers4craft/paint.software)
